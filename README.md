# nazir.design

Portfolio of Nazir Hossain, character animator and motion designer.

- `index.html`: home (reel, experience, process, hybrid AI workflow, contact)
- `projects.html`: feature films and full filmography
- `films/`: clips, stills and posters
- `brand/nh-logo.svg`: logo

Plain HTML, CSS and JavaScript (GSAP, ScrollTrigger and Lenis from CDNs). No build step: GitHub Pages serves the files as they are.
